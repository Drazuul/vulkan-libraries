# vulkan-libraries


A set of code exercises to learn Vulkan 3D Graphics API and build a simple game engine library

## Chapter 0 - Math Foundations

Follow the first few chapters of scratchapixel or Raytracing in One Weekend to  understand the fundamentals of vector and matrix operations

Write your own `Vec3`, `Vec4`, and `Mat4` structs in a single `math3d.h` header file.

Write a small `main.cpp` that tests `dot()`, `cross()`, and multiplying a point by a `translate()` matrix.

## Chapter 0 - Math Foundations

Graphics APIs make heavy use of Linear Algebra and Vector Operations, so write your own `math3d.h` header file that voncatins `Vec3`, `Vec4` and `Mat4` definitions and operations.

Because I am familiar with C Patterns, `struct` and psuedo-OOP pointer arithmetic, but not comfortable using C++ `class` types, focus on writing these operation with practical OOP C++ patterns

The beginning sections of both **scratchapixel** and **Ray Tracing in One Weekend** go over these 3d math types and operations, but do not focus heavily on following these guides, as I have already chosen **vulkan-tutorial** as my preferred "Start-to-finish" tutorial

When `math3d.h` is built, I can review OpenGL Mathematics `glm` Library, as this library is likely what will be used to build projects later on.
